# Bangla Creator Studio

A free, mobile-friendly, bilingual (Bangla + English) social content toolkit.

## Features
- Caption Maker
- YouTube Shorts title and script starter
- Video hook ideas
- Hashtag suggestions
- Thumbnail text ideas
- Content idea generator
- Copy and share actions
- Dark/light theme
- No sign-up; generation runs locally in the browser

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a **Public** repository on GitHub (for example, `bangla-creator-studio`).
2. Upload `index.html`, `README.md`, and `LICENSE` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Important
This first version uses curated local templates, not a connected AI model. It does not guarantee virality or audience growth. Improve suggestions with real user feedback and test outputs before publishing.
